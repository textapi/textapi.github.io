About TextAPI

The power of text extraction, manipulation, and analysis in an API.

What and why

TextAPI puts modern natural language processing into the hands of the everyday programmer and the industrious business owner. You don't need to be Google or Amazon to use NLP — TextAPI surfaces text analysis, extraction, and question answering through a language-agnostic web API, so a developer working in PHP, C#, or anything else can leverage it with a single HTTP call.

The full list of endpoints lives in the interactive API docs.

Getting access

API keys are issued instantly from our storefront on APIDirectory with metered, pay-per-request billing. TextAPI is also a verified, claimed listing in the APIDirectory registry.
