Works from any language

If it can make an HTTP request, it can use TextAPI.

curl "{{ site.api_base }}/ner?text=Apple+is+buying+a+U.K.+startup" \
  -H "X-API-Key: $TEXTAPI_API_KEY"

{"spans": [{"text": "Apple", "start": 0, "end": 5, "label": "ORG"},
           {"text": "U.K.", "start": 19, "end": 23, "label": "GPE"}]}
import os
import requests

r = requests.get("{{ site.api_base }}/ner",
                 params={"text": "Apple is buying a U.K. startup"},
                 headers={"X-API-Key": os.environ["TEXTAPI_API_KEY"]})
print(r.json()["spans"])
const res = await fetch("{{ site.api_base }}/ner?text=" +
  encodeURIComponent("Apple is buying a U.K. startup"),
  { headers: { "X-API-Key": process.env.TEXTAPI_API_KEY } });
const { spans } = await res.json();

Every call goes to api.textapi.com with your key in the X-API-Key header — get one, plus code samples for every endpoint, on the storefront.

Questions, answered

How is TextAPI billed?

Through our storefront at developers.textapi.com, backed by Stripe. Billing is metered: every request counts, you get one invoice a month for exactly what you used, and you can cancel any month. No tiers, no seats, no minimums.

How do I get an API key?

Instantly — subscribe on the storefront and your key is issued and emailed the moment checkout completes.

Can I try it before subscribing?

Yes. The storefront issues a free key (1,000 requests a month), and every endpoint can be exercised from the interactive docs.

What counts as a request?

Each API call made with your key counts as one metered request, whichever endpoint it hits.
